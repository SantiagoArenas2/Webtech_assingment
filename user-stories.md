# User Stories — Roomies

Roles: **Visitor** (not authenticated), **Member** (can act as *host* and/or *seeker*), **Moderator**.

## Visitor

1. As a visitor, I want to search for rooms filtering by neighborhood, maximum rent, and availability date, so that I can find options that fit what I need without having to create an account first.
2. As a visitor, I want to view the details of a listing (photos, price, neighborhood, description, amenities), so that I can decide if I'm interested before signing up.
3. As a visitor, I want to see a property's reviews, so that I know what experience other seekers had before applying.
4. As a visitor, I want to create an account with my email, so that I can apply to rooms, publish properties, and save my searches.

## Member — as Host

5. As a host, I want to publish a property with its address, neighborhood, and general amenities, so that I can later add the rooms available inside it.
6. As a host, I want to add, edit, and delete rooms within a property (with photos, price, availability date, and description), so that I can keep my listings up to date.
7. As a host, I want to mark a room as unavailable or occupied, so that it stops appearing in searches without having to delete it.
8. As a host, I want to see the list of applications a room has received, so that I can review who is interested.
9. As a host, I want to shortlist one or more applicants, so that I can focus on scheduling visits only with them.
10. As a host, I want to schedule a visit date with a shortlisted applicant, so that they can see the room before deciding.
11. As a host, I want to accept an applicant after the visit, so that I can close the process and mark the room as rented.
12. As a host, I want the other active applications for that room to be automatically rejected when I accept an applicant, so that no one else is left waiting for a response.

## Member — as Seeker

13. As a seeker, I want to apply to a room with a message for the host, so that I can express my interest and tell them a bit about myself.
14. As a seeker, I want to see the status of my applications (submitted, shortlisted, rejected, accepted), so that I know where each one stands.
15. As a seeker, I want to withdraw an application I already submitted, so that I can drop out of the running if I changed my mind or found another room.
16. As a seeker, I want to save rooms I'm interested in to a favorites list, so that I can come back to them later without having to search again.
17. As a seeker, I want to leave a review of a property after visiting or renting there, so that I can share my experience with other seekers.
18. As a seeker, I want to report a listing that looks fake, misleading, or inappropriate, so that I can help keep the platform trustworthy.

## Member — common to host and seeker

19. As a member, I want to edit my profile (name, photo, contact details), so that the other party knows who they're dealing with.
20. As a member, I want to receive notifications when an application's status changes (new, shortlisted, accepted, rejected) or when I receive a report on one of my listings, so that I don't have to check manually.

## Moderator

21. As a moderator, I want to see a queue of reported listings, so that I can review them and decide whether action is needed.
22. As a moderator, I want to remove a listing and notify the host, so that I can take down a listing that violates the platform's rules.
23. As a moderator, I want to dismiss a report with no action if I don't find a real violation upon review, so that I don't penalize legitimate listings.
24. As a moderator, I want to manage the neighborhood catalog (add, edit, delete), so that search and listing options stay consistent.
25. As a moderator, I want to manage the amenities catalog (add, edit, delete), so that hosts always choose from a standardized list when describing their properties.
26. As a moderator, I want to suspend the account of a member with repeated, justified reports, so that I can protect the rest of the community.
